About

This is a demonstration bookdown page for the arcea R package. Here, the bookdown would be organized into separate chapters for each indicator or group of similar indicators, and files for each chapter would be stored in the chapters/ folder. Individual chapter folders would need to be explicitly listed in _bookdown.yml to appear in the rendered book.
